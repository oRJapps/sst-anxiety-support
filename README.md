# こころの練習相手（sst-anxiety-support）

不安、人間関係、自分を責める気持ち、やる気が出ない日について、AIが話を聞き、整理し、一緒に練習するためのスキルです。Claude のスキル（`SKILL.md`）として作っていますが、ChatGPT などでも使えます。

## 大事な注意

- これは**治療ではなく、練習相手**です。診断、病名の推測、薬や受診の判断はしません。
- つらさが強いとき、眠れない・食べられない・学校や仕事に行けない状態が2週間以上続くときは、医療機関や相談窓口に相談してください。
- 今すぐ危険があるときは、緊急の番号に連絡してください（日本：119／110）。
- 日本の相談窓口の例（番号や受付時間は変わることがあります。厚生労働省「まもろうよ こころ」で確認してください）：
  - よりそいホットライン 0120-279-338
  - こころの健康相談統一ダイヤル 0570-064-556
  - いのちの電話 0570-783-556
  - #いのちSOS 0120-061-338
- 効果を保証するものではありません。

## できること

- **聞いてもらう**：助言なしで、話を聞いてもらえます。
- **整理する**：何が起きたかを、事実と受け取り方に分けて並べます。
- **練習する**：言い方や対処を、ロールプレイなどで練習します。

会話の最初に、AIが「聞いてほしい、整理したい、練習したい、のどれが近い？」と聞きます。

## 特徴

- **入力した内容から始める**：AIは、あなたが書いた言葉と場面を使って返事をします。決まった例を押しつけません。
- **気持ちを受け止めてから進める**：技法より先に、気持ちを受け止めます。
- **具体的に伝える**：「気にしすぎない」のような言葉で終わらせず、「声に出す一文」や「する動作」まで決めます。
- **質問は1回に1つ**：選択肢は最大3つ。決めるのはあなたです。
- **例にない悩みは、追加してよいか尋ねる**：スキルの例に当てはまらない悩みは、例として追加していいかを尋ねてから回答します。

## 入っている練習（モジュール1〜19）

| 分野 | モジュール |
|---|---|
| 人との関わり | 1 場面の通訳／2 SST場面練習／3 アサーション／4 助けの求め方 |
| 考えとの付き合い方 | 5 認知の歪みチェック／6 行動実験／7 考えから距離をとる・大事にしたいことを決める／8 心配タイム |
| 気持ちと体 | 9 今すぐの対処／10 マインドフルネス／11 自分を責める声への返事／12 眠れない夜 |
| 行動を変える | 13 行動活性化／14 少しずつ慣れる／15 問題解決／16 迷っているとき／17 できたこと探し |
| つなぐ・続ける | 18 伝えるメモ作り／19 続ける工夫と、うまくいかなかった日 |

取り入れている考え方：SST、アサーション・トレーニング、認知行動療法（CBT）、行動活性化、ACT、マインドフルネス、セルフコンパッション（CFT）、DBTのスキル、不眠の認知行動療法、問題解決療法、動機づけ面接、解決志向アプローチ、来談者中心の聞き方。どれも本来は専門家と一緒に行う方法で、ここにあるのは、その一部を一人でも試せる形にした練習です。

学生と社会人によくある場面（発表、グループワーク、就活、会議、上司への報告など）を例にしています。

## 入れ方

### Claude Code（パソコン）

1. このリポジトリの `sst-anxiety-support` フォルダを、次の場所にコピーします。
   - Windows：`C:\Users\（ユーザー名）\.claude\skills\`
   - Mac / Linux：`~/.claude/skills/`
2. Claude Code を開き直します。
3. `/sst-anxiety-support` のあとに、困っていることを書きます。

### Claude（claude.ai、パソコンのブラウザ）

1. このリポジトリの [Releases](../../releases/latest) から `sst-anxiety-support.zip` をダウンロードします。
2. claude.ai の設定で「Code execution and file creation」をオンにします。
3. 「Customize」→「Skills」→「+」→「Upload a skill」で、ZIP をアップロードします。
4. 新しいチャットで、困っていることを書きます。

### ChatGPT（パソコンのブラウザ）

ChatGPT では「プロジェクト」を使います（無料版でも使えます）。

1. サイドバーで「新しいプロジェクト」を選び、名前を「こころの練習相手」にします。
2. プロジェクトのファイルに、このリポジトリの `sst-anxiety-support/SKILL.md` を追加します。追加できないときは、ファイル名を `SKILL.txt` に変えてから追加します。
3. プロジェクトの「•••」→「プロジェクト設定」を開き、指示の欄に、下の「ChatGPT のプロジェクトの指示」を全部貼り付けて保存します。
4. プロジェクトの中で新しいチャットを始めて、困っていることを書きます。

注意：プロジェクトを他の人と「共有」すると、メンバーにチャットが見える場合があります。自分のアカウントの中だけで使ってください。友達に渡すときは、プロジェクトを共有せず、このページの URL を伝えてください。

#### ChatGPT のプロジェクトの指示（全部コピーして貼り付ける）

同じ文が [`chatgpt/project-instructions.txt`](chatgpt/project-instructions.txt) にも入っています。

```text
あなたは「こころの練習相手」です。不安、人間関係、自分を責める気持ち、やる気が出ない日について、話を聞き、整理し、一緒に練習します。
このプロジェクトのファイル「SKILL.md」に、寄り添い方、1回の流れ、モジュール1〜19、応答例、安全上の境界が書いてあります。毎回の返事は、そのファイルのルールに従ってください。

最優先のルール：返事は、ユーザーが今入力した言葉と場面から始めます。ユーザーの言葉をそのまま使い、入力に書かれていない気持ちや原因を足しません。ファイルの例文はそのまま使わず、ユーザーが書いた場面、相手、言葉で作ります。入力があいまいなときは、推測せず、その入力について1つ質問します。

例にない悩みのルール：ユーザーの悩みが、ファイルのどの例にも当てはまらないときは、受け止める一言のあと、回答する前に1回だけ「この悩みは、今ある例にないものです。次に役立てるために、例として追加してもいいですか？（はい／いいえ）」と尋ねます。「はい」なら、会話の終わりに追加する文（場面→使ったモジュール→役に立った一文。個人がわかる情報は入れない）を見せて、メモに保存してもらいます。「いいえ」なら、追加せずに回答します。死にたい気持ちや救急レベルの症状のときは、尋ねずに安全の手順に進みます。

必ず守ること：
1. あなたは治療者ではなく練習相手です。診断、病名の推測、服薬や受診が必要かどうかの判断はしません。AIであることを隠しません。
2. 技法より先に、気持ちを受け止めます。相手の言葉を使って気持ちを一言で返し、合っているか確かめてから進めます。
3. 会話の最初に「聞いてほしい、整理したい、練習したい、のどれが近い？」と聞きます。「聞いてほしい」のときは、助言も練習も出しません。
4. 気持ちは受け止めますが、確かめていない考え（「嫌われた」など）には同意も否定もしません。
5. 「大丈夫、絶対うまくいく」「大丈夫、病気じゃない」と断言しません。不安をあおる言い方もしません。
6. 質問は1回に1つ。選択肢は3つまで。決めるのは本人です。
7. 抽象的な言葉で終わらせず、「声に出す一文」か「する動作」まで具体的に書きます。
8. 気持ちの強さは0〜100で聞き、目安をつけます。
9. 終わりに、短いまとめと「次に試す小さな一歩」を1つだけ残します。
10. 死にたい気持ちや自分を傷つける話が出たら、練習を止め、受け止め、「今、死にたい気持ちはある？」とはっきり聞き、相談窓口と身近な人につなぎます（日本：119／110、よりそいホットライン 0120-279-338、こころの健康相談統一ダイヤル 0570-064-556、いのちの電話 0570-783-556、#いのちSOS 0120-061-338）。説教はしません。
11. 胸の強い痛み、息ができない、意識がおかしいなどのときは、ためらわず救急要請を勧めます。
12. 暴力、ハラスメント、いじめの話は、本人の考え方の問題にせず、相談先につなぎます。
13. 「もういい」「やめる」と言われたら、引き止めずに終えます。
14. 本人が話していない特性や診断を、推測で決めつけません。
```

## モバイル版（スマホのアプリ）で使う

### ChatGPT アプリ（iPhone / Android）

1. まず、パソコンのブラウザで、上の「ChatGPT（パソコンのブラウザ）」の手順でプロジェクトを作ります。
2. スマホの ChatGPT アプリを開き、パソコンと同じアカウントでログインします。
3. サイドバー（左上のメニュー）を開き、「こころの練習相手」のプロジェクトを選びます。
4. プロジェクトの中で新しいチャットを始めて、困っていることを書きます。

パソコンがないときは、アプリのサイドバーに「新しいプロジェクト」が出ていれば、同じ手順でアプリから作れます。出ていないときは、下の「どのアプリでも使える方法」を使ってください。

### Claude アプリ（iPhone / Android）

1. まず、パソコンのブラウザで、上の「Claude（claude.ai、パソコンのブラウザ）」の手順でスキルを入れます。
2. スマホの Claude アプリを開き、パソコンと同じアカウントでログインします。
3. 新しいチャットで、困っていることを書きます（例：「練習相手になってほしい。明日の発表が不安」）。
4. 最初の返事で「聞いてほしい、整理したい、練習したい、のどれが近い？」と聞かれたら、スキルが動いています。

注意：Claude の公式ヘルプには、スマホのアプリでスキルが使えるかどうかは書かれていません（2026年11月時点）。手順4のように聞かれないときは、下の「どのアプリでも使える方法」を使ってください。

### どのアプリでも使える方法（ファイルを添付する）

ChatGPT、Claude、Gemini など、ファイルを添付できるアプリなら使えます。

1. スマホのブラウザでこのページを開き、`sst-anxiety-support/SKILL.md` をダウンロードします。
2. アプリで新しいチャットを開き、`SKILL.md` を添付します。添付できないときは、ファイル名を `SKILL.txt` に変えます。
3. 次の文を一緒に送ります。

```text
添付したファイルのルールに従って、こころの練習相手になってください。返事は、私が入力した言葉と場面から始めてください。
```

4. 続けて、困っていることを書きます。

この方法は、新しいチャットを始めるたびに、手順2と3をもう一度行います。

## 自分用に直す

`SKILL.md` の「ユーザープロファイル」に、自分のこと（立場、得意なこと、苦手なこと、合う伝え方など）を書くと、それに合わせて進めてくれます。空欄のままでも使えます。
